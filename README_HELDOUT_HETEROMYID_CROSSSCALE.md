# Held-out heteromyid cross-scale validation

This branch is an independent, effect-blind follow-up to the completed sex-packing development programme.

Current stage: estimability only.

Previously inspected species are excluded before any counts are viewed. The primary sample threshold is N>=5 males and N>=5 females. No held-out Packing_z, movement distance, sex effect, sign, CI or p-value may be computed until the cross-scale estimability gate is frozen and a second effect-analysis lock is committed.
