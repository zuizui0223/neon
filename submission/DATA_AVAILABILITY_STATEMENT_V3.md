# Data Availability Statement — ScholarOne form, V3

The underlying biological observations are publicly available from the National Ecological Observatory Network Small Mammal Box Trapping product (DP1.10072.001), RELEASE-2026, DOI 10.48443/A83H-TB34.

For double-anonymized peer review, the submission includes an anonymous reproducibility archive containing the derived summaries from the original 16-site confirmatory programme and the independent 11-site prospective mechanism programme; the frozen site rosters, protocols and response authorization; standardized trait tables; deterministic analysis and figure-generation code; integrity tests; and per-file SHA-256 manifests. The review archive contains no author-identifying repository metadata or source-control history.

After acceptance, the reproducibility package will be deposited in a public repository with a persistent identifier and the Data Availability Statement will be updated with the final citation and link.
