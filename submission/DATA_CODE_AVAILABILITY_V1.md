# Data and code availability — submission draft

The underlying biological observations are publicly available from the NSF National Ecological Observatory Network (NEON) Small Mammal Box Trapping product, DP1.10072.001, RELEASE-2026, DOI 10.48443/A83H-TB34.

The study repository contains the derived site-level summaries, frozen protocols and response locks, deterministic analysis code, integrity tests, claim matrices and figure-generation code required to reproduce the reported manuscript summaries.

For double-anonymized peer review, an anonymous review archive will be prepared from the repository without author-identifying metadata or links. After acceptance, the reproducibility package will be deposited publicly with a persistent identifier.
