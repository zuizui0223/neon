# Data Availability Statement — ScholarOne form, V2

The underlying biological observations are publicly available from the National Ecological Observatory Network Small Mammal Box Trapping product (DP1.10072.001), RELEASE-2026, DOI 10.48443/A83H-TB34.

For double-anonymized peer review, the submission includes an anonymous reproducibility archive containing the derived site-level summaries, frozen protocols and response locks, deterministic analysis code, integrity tests, claim matrices and figure-generation code required to inspect and reproduce the reported manuscript summaries. The review archive contains no author-identifying repository metadata or source-control history.

After acceptance, the reproducibility package will be deposited in a public repository with a persistent identifier and the Data Availability Statement will be updated with the final citation and link.
