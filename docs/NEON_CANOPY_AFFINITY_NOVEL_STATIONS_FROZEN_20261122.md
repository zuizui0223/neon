## Primary new ecological question

When individual tags shared between seasons have already been excluded, **do the same mammal genera use similarly canopy-tall/canopy-short locations in the second season at DIFFERENT original trap positions**? This is a stronger and distinct hypothesis than repeating EXACT genus×trap hits: exclude identical genus-specific stations from the season-B environmental score. It does not distinguish true habitat choice from taxon-dependent trap capture probability; no resource/biomass or interspecific competition effect is claimed.

## One frozen observed response (canopy at NONIDENTICAL stations)

For each selected original adjacent season pair and each canonical 100-station grid:
1. For each season A/B separately, take the **mean 1m CHM reference canopy height at a station across the three source capture dates**; reject any unit with nonnumeric/invalid source CHM from any of its 600 seasonal station-date samples (no imputation). Within each season's full 100 trap stations, convert height to **midrank** [0,1] as `(rank-0.5)/100`, breaking ties using their average rank and NOT assigning zero canopy values random jitter.
2. For each original source genus `g`, compute `a_g = mean(midrank_A[traps in A_g]) - 0.5` (the capture-associated canopy preference in season A; equal weight per original used station, NOT capture counts). Compute `novel_B_g = B_g \ A_g`, and `b_g = mean(midrank_B[traps in novel_B_g]) - 0.5` if that set is nonempty, else `b_g = 0`.
3. Single unit statistic `T = mean_over_all_original_genera(a_g * b_g)`. A positive T indicates environmental canopy-affinity agreement for original genus labels at **non-identical season-B trap positions**; T is NOT a true niche coefficient and NO exact-station B hit enters `b_g`.
4. Require observed original unit has ≥2 genera with at least one novel B trap, and original height across full 100 positions has more than one distinct CHM value each season. If these fail, that original source unit is uninformative and counted, not replaced. Do not select canopy height thresholds, tree species, vegetation products, genera, elevational strata or plots after seeing results.
