# SCR sigma dynamic-state robustness benchmark v2

Date: 2026-10-03

Status: robustness design added after the primary v1 consequence benchmark. It does not reopen the stopped empirical SCR effect analysis.

## Why this benchmark exists

The v1 consequence benchmark deliberately reproduced the observed repeat-capture frequency by expanding an already captured animal-night into one or two check-level records. That design is useful as an observation-process stress test, but it means the CHECK representation contains two departures from a standard static SCR model:

1. spatial state mixing;
2. within-night encounter dependence introduced by conditional record expansion.

The large negative CHECK bias at large generating sigma therefore cannot be attributed uniquely to state mixing.

This v2 benchmark removes the second component.

## Sequential generator

Each replicate begins with one simulated population and one static baseline activity centre per animal.

For each of three nights:

1. the animal population begins at the baseline centres;
2. check 1 is generated directly with `secr::sim.capthist`;
3. after an animal's first capture that night, its within-night state centre may shift once;
4. checks 2 and 3 are generated independently with `secr::sim.capthist` around the current state centre;
5. at the next night, all state centres reset to the baseline centres.

Thus every physical check is generated by the same SCR detector process. The only deliberate misspecification fitted later is that the latent centre can change after capture within a night.

## Empirical anchor

The transition-vector distribution is the already-opened pooled PEMA + PEER material first-to-last detector displacement kernel.

Frozen empirical quantities reused:

- 1,520 valid captured individual-nights;
- 592 repeat-observed nights;
- 426 material first-to-last transitions;
- repeat fraction = 0.3895;
- changed fraction among repeat nights = 0.7196;
- material transition RMS length = 16.94 m;
- material transition median length = 12.5 m.

The capture-triggered shift probability in this stress test is fixed to 0.7196. This is a calibration parameter, not an estimate that handling caused 71.96% of repeat-night changes.

## Shift magnitude series

The empirical displacement vectors are multiplied by:

- 0.0;
- 0.5;
- 1.0;
- 1.5.

The zero multiplier is the implementation negative control. The 1.0 multiplier uses the observed detector-to-detector vector scale. The other multipliers test whether sigma sensitivity changes monotonically with the magnitude of observation-conditioned state displacement.

No multiplier is selected from fitted sigma results.

## SCR design

- detector array: 7 x 7 multi-catch traps;
- spacing: 6.25 m;
- checks: 3 per night;
- nights: 3;
- generating detection function: half-normal;
- g0 = 0.15;
- generating sigma = 6.25, 12.5, 25 m;
- density = 60 animals ha^-1;
- simulation / fitting buffer = 100 m;
- analysis: conditional likelihood, HN, g0 ~ b, sigma ~ 1.

Each simulated record set is represented as:

- CHECK: all physical checks as occasions;
- FIRST: first detector state retained per animal-night;
- LAST: last detector state retained per animal-night.

## Primary purpose

This benchmark is not intended to replace v1 unless it reveals a substantive contradiction.

It asks a narrower robustness question:

> If repeated checks are generated sequentially by a valid SCR detector process and only the within-night spatial state changes after capture, does the qualitative conclusion remain that finer check-level encoding is not automatically estimand-equivalent to nightly FIRST/LAST encoding?

## Required diagnostics

The output must report:

- zero-shift median sigma bias for CHECK, FIRST and LAST;
- realized repeat-capture fraction;
- realized material-change fraction among repeat nights;
- realized changed-night distance scale;
- sigma bias by representation, true sigma and shift multiplier;
- paired CHECK/FIRST, CHECK/LAST and LAST/FIRST sigma ratios.

The zero-shift family must have maximum absolute median sigma bias <10% before non-zero shift cells are interpreted.

## Execution / interpretation gate

The robustness run is accepted for interpretation only if the zero-shift negative control passes the pre-specified <10% maximum absolute median sigma-bias criterion. Realized repeat-capture and changed-night fractions in non-zero cells are reported as calibration diagnostics and are not tuned after seeing fitted sigma effects. The v1 consequence benchmark remains the primary result unless v2 reveals a substantive qualitative contradiction.

## Claim boundary

The benchmark may support a conditional statement about a capture-triggered state-change process.

It may not be used to claim:

- handling caused the San Jacinto displacement pattern;
- the empirical PEMA or PEER sigma is biased by the simulated amount;
- CHECK-level SCR is generally biased;
- FIRST or LAST is universally preferable.

The real-data two-species SCR gate remains stopped.
