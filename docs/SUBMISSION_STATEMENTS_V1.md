# Submission statements — live-trap aliasing v1

## Data availability

The empirical validation is a secondary analysis of publicly available data deposited in Figshare with the study by Chock, Shier & Grether (2022). The source dataset is available at DOI **10.6084/m9.figshare.18295520.v1**. The analysis freezes and verifies the source file checksum before use.

## Code availability

The generic temporal positional-aliasing diagnostic, deterministic sensitivity-bound implementation, simulation benchmark, empirical validation pipeline, tests, and figure-generation code are maintained in the review branch for this manuscript. Code is released under the **MIT License**. A versioned standalone archival release should be created before final submission/acceptance and its DOI or persistent repository URL inserted here.

## Ethics statement

This study is a secondary analysis of previously collected public data and involved no new animal capture or handling. Chock, Shier & Grether (2022) state that applicable institutional guidelines for animal care and use were followed in the original field study.

The empirical confirmatory outcome was frozen prospectively for two held-out Cricetidae species before their first-to-last positional outcomes were inspected. The repository retains the pre-outcome lock, result receipt, workflow provenance, and simulation benchmark. A prospectively planned downstream MCP home-range sensitivity analysis was not authorized because its effect-blind support gate failed; no MCP area effect is claimed.
