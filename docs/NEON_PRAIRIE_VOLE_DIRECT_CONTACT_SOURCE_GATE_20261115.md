# 2025 prairie vole logger vs trapping contact source — independent detector preflight

November 15, 2026. ONE NEON mammal ecology PR #23. Source-only feasibility audit, not a statistical result.

Davidson et al. (2025), Journal of Mammalogy, DOI 10.1093/jmammal/gyaf032, already compared live trapping with on-animal BLE ProxLogs recording proximity approximately 5–6 cm. Original study used 24 shared vole individuals in its paired network comparison; recorded trap association predicted real proximity only weakly (published QAP r=0.148, R²=0.02). This original result is PRIOR ART, not a new NEON discovery. Source devices can stop logging when their 4,000-record memory is full, collared individuals are an incomplete subsample and logger records do not automatically provide functioning absence effort.

Paper's official public dataset is Figshare project 228462: https://figshare.com/projects/Journal_of_Mammalogy_-_Methods_for_measuring_fine-scale_social_proximity_in_small_mammals/228462 .

First stage calls only documented public Figshare API: project GET, project articles GET, article detail GET. It exports names, public article IDs, DOI, approximate sizes, MD5-presence but NEVER animal tag IDs, raw event records, or direct contact evidence. Filename matches are provisional and do not establish source usability.

Only if accessible original raw capture events, proximity logger events, stable PIT-to-collar identity crosswalk, logger deployment/operability periods, at-risk dyad denominator and time-matched window boundaries are all confirmed may a new effect be frozen before outcome. The original 2025 paper already did same-observation-mode network regression; repeating R²=0.02 is not independent scientific novelty.

New question, if feasible: does captured spatial partner proximity predict which individual pairs actually meet after correcting dyad observation opportunities, season/density and independent collar function? This cannot be tested in the Finnish bank-vole individual-dyad cohort unless independently recorded collars exist for THOSE same animals; a different species/location only provides an illustrative biological counterpoint.
