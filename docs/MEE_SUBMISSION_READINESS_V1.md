# MEE submission-readiness checklist — live-trap aliasing v1

Date: 2026-09-30

## Journal fit

- [x] Methodological approach, not biological case study, is central.
- [x] Generic code independent of the empirical schema.
- [x] Simulation benchmark precedes empirical validation in manuscript structure.
- [x] Broad applicability argued at the level of repeated-location ecological data, not one taxon.
- [x] Empirical validation is prospectively held out.
- [x] Failure modes and observation-process dependence are explicitly demonstrated.
- [x] Deterministic downstream sensitivity bounds are included.
- [ ] Add at least one compact worked example using the generic CLI/input schema.
- [ ] Decide whether an external non-live-trapping example is necessary or whether broad applicability of the diagnostic is sufficiently demonstrated conceptually/simulated.

## MEE format

- [x] Research Article is the intended article type.
- [x] Target <=7,000–8,000 words including references/captions/statements.
- [x] Abstract drafted in numbered 1–4 structure.
- [x] Standard sections planned.
- [x] Data/Code for peer review statement drafted.
- [ ] Continuous line/page numbering at final document generation.
- [ ] Separate title page at submission.
- [ ] Author contributions / acknowledgements / conflict / ethics / data availability finalized.

## Code policy

- [x] MIT open-source license added.
- [x] Generic diagnostic included.
- [x] Unit tests included.
- [x] Simulation benchmark included and frozen.
- [x] Reproducible empirical result receipt included.
- [ ] Create final standalone review repository or archival release.
- [ ] Add CITATION.cff and versioned release/tag.
- [ ] Add minimal environment/dependency file.

## Scientific boundaries

- [x] Repeat-conditioned empirical fractions explicitly not generalized to all nights.
- [x] All-night directly observed fractions labeled observational lower bounds.
- [x] First-to-last span explicitly not treated as full movement path.
- [x] Theory bounds described as practical geometry, not mathematical novelty.
- [x] Home-range downstream effect not claimed; frozen support gate failed.
- [x] San Jacinto magnitude not generalized universally.

## Before pre-submission enquiry

- [ ] Focused literature search completed and references verified.
- [ ] Figures 1–4 rendered.
- [ ] Manuscript v0.5 with Introduction/Methods/Results/Discussion prose.
- [ ] Generic example workflow tested end-to-end on a small synthetic CSV.
- [ ] Repository cleaned of unrelated project material or exported standalone.
