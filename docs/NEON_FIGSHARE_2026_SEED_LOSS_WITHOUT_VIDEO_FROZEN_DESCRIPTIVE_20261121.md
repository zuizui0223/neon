## Primary descriptive quantity and falsification/quality criteria (fixed before seed-count values)

Classify each of the 288 original four-key station-night records by exact presence/absence of the original composite key in the 3,243-row `All Foraging Clean` camera event table. This is **recorded camera foraging event presence**, NOT actual animal visitation/nonvisitation, not an independent operational camera detector status. Source visit rows are not independent animals or unique visits.

For each identified station×night, independently for original **WP (white pine)** and **RO (red oak)** seed counts:
- Check `{WP,RO}.seeds.set` and `{WP,RO}.seeds.left` are finite nonnegative original count fields. Integer-valued expected for number of seeds; noninteger or negative set/left **SOURCE STOP** (do not round).
- Numerically calculate only for a station×night with all four seed count fields nonmissing, both species offered quantity >=0, and `left ≤ set` for BOTH types (no unrecognized seed additions). Original `set=0,left=0` valid: cannot contribute seed disappearance; do not treat zero as missing. If ANY original station-night has `left>set`, record invalidity and scientific **SOURCE STOP** before aggregate results. Do not clip negative removal or selectively remove anomalous observations.
- **All-four-field complete source availability threshold**: >=100 video-event-positive keyed station nights AND >=100 no-event keyed station nights must have all four numeric original set/left counts; otherwise SOURCE STOP without a response estimate. This threshold was fixed before original seed-disappearance values were opened.
- **Primary ecological-descriptive record**: `N_no_video_event_with_at_least_one_seed_missing` among all complete original no-event station-nights; `missing` means **number set minus number remaining at dawn** >0 in at least one seed type. Report numerator, denominator, fraction. Do NOT label missing seeds as verified seed consumption or dispersal by a specific animal.
- **Secondary descriptive quantities** (fixed now): N with missing seed by camera-event-positive station-night vs no-event group; total WP and RO seed counts set and missing separately for both groups; fraction of ALL observed source station seed disappearances (WP+RO physical seed counts) that occurred on the no-recorded-video-event nights. Same source counts per original seed type; no cross-species seed mass conversion.
- Report only aggregate number/seed count by two groups, NOT individual PITs, site, GRID, geographic coordinates, exact dates, forest treatment/season contrasts, per-species animal behaviors, p-values or predictive models. No cherry-picked subgroup rescue.

## Scientific interpretation boundary

If seed loss is positive at nights without recorded video foraging, the result demonstrates only that **seed loss at baited field stations is not completely attributable to the deposited positive video event records**, which is consistent with prior authors' acknowledgment of seeds missing without video; not proof of undetected small mammals, missing animal presence, ecological learning, competitive consumption, resource depletion in natural vegetation, nor NEON/Portal true niche space use. If zero, that is a descriptive **non-support** for these source-defined no-event records, not absence of nocturnal seed predators. The 2026 original paper has already analyzed seed disappearance as an original community outcome; any numerical result is a within-source descriptive audit of representation and novelty remains limited.
