# PEMA stationary-SCR displacement null v1

Date: 2026-10-06

Status: design frozen before opening the new stationary-null simulation output.

## Question

Can the observed within-night FIRST-to-LAST displacement distribution for PEMA be generated by a time-reversal-symmetric, static SCR process with one persistent activity centre and independent check-level detections?

This is a diagnostic of whether the empirical within-night displacement scale itself requires an ordered post-capture state shift. It is not a new confirmatory ecological endpoint and it does not reopen the stopped two-species SCR programme.

## Empirical target

Use the already-opened San Jacinto PEMA repeat-capture nights from the frozen source file.

For all repeat-observed PEMA individual-nights, compute without excluding same-trap repeats:

- repeat-night count;
- changed-trap fraction at the 6.25 m detector-spacing threshold;
- FIRST-to-LAST vector RMS distance;
- per-axis RMS, defined as sqrt(mean((dx^2 + dy^2)/2));
- median and 90th percentile displacement;
- mean directed displacement vector and its magnitude.

The frozen support count is 485 PEMA repeat nights. The source file checksum remains
`ec70b40fdcc66a3f9c07a3fda64b5eda06d251a899b9bc99cc5c5dff8c4ab301`.

## Static SCR null

Simulate the San Jacinto 7 x 7 multi-catch detector grid with 6.25 m spacing.

For every simulated night:

1. generate a fresh Poisson population with static activity centres;
2. hold each activity centre fixed for all three within-night checks;
3. generate each check independently with `secr::sim.capthist`;
4. use a half-normal detection function;
5. retain FIRST and LAST detector locations only for animal-nights detected on at least two checks;
6. never add a post-capture displacement or ordered state transition.

The detector layout, 100 m population buffer and density 60 animals ha^-1 follow the validated stationary benchmark already used in the manuscript.

## Sigma bracket

Do not tune sigma to the displacement result.

Use the already-opened post-stop PEMA SCR interval and point estimates:

- 7.7806 m: LAST 95% lower bound;
- 8.5625 m: LAST point estimate;
- 8.8515 m: FIRST point estimate;
- 9.7559 m: FIRST 95% upper bound.

This brackets the empirical stationary spatial scale already reported in the manuscript.

## Detection-probability sensitivity

The pooled empirical SCR fit used `g0 ~ b + grid + bout`, so no single scalar g0 is the empirical model. To avoid inventing one fitted value, use a broad scalar sensitivity grid:

- g0 = 0.03, 0.06, 0.10, 0.15, 0.25.

The spatial conclusion is treated as robust only if it does not depend on one tuned g0 value.

The empirical captured-night repeat fraction is reported as an observation-process calibration diagnostic. Cells closest to that fraction may be highlighted descriptively, but no cell is selected using the displacement metrics.

## Monte Carlo comparison

For each sigma x g0 cell:

- simulate until at least 2,500 repeat-observed animal-nights are accumulated;
- retain the full pooled null distribution;
- bootstrap 2,000 pseudo-datasets of 485 repeat nights;
- compute the same empirical displacement summaries in every bootstrap sample.

Report for each metric:

- null median;
- 2.5% and 97.5% quantiles;
- fraction of bootstrap values >= the observed value;
- fraction <= the observed value;
- whether the observed value lies inside the 95% null interval.

No significance threshold is used to promote or demote the manuscript claim. These are posterior-predictive-style reference diagnostics with parameters partly informed by the same data.

## Interpretation boundaries

If the observed displacement scale lies inside the stationary null over the empirical sigma bracket, the data do not require an ordered within-night state shift to explain displacement magnitude.

If the observed displacement scale is larger than the stationary null across the full bracket, that is evidence for additional within-night dynamics, but not by itself evidence that handling caused them.

If the observed changed-trap fraction is lower than the stationary independent-check null while the displacement scale is compatible, that pattern is consistent with short-term positional persistence or serial dependence. It does not identify its biological mechanism.

This analysis cannot:

- infer a handling effect;
- establish FIRST or LAST as biologically correct;
- rescue the stopped two-species SCR gate;
- convert the ordered-transition stress test into an empirical bias estimate;
- prove full temporal exchangeability.

Its sole role is to determine whether the empirical displacement scale itself exceeds what a static SCR observation process can generate.
