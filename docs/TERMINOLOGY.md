# Terminology contract

| Frozen implementation term | Ecology-facing term |
|---|---|
| canonical world | prespecified trap-neighbourhood adjacency criterion |
| world survival | criterion satisfaction |
| survival fraction | continuity fraction |
| community survival fraction | pooled-community continuity fraction |
| max species survival fraction | best-species continuity fraction |
| emergent connectivity gain | community-minus-best-species continuity gain |
| strict emergent world | strict emergent adjacency criterion |

Do not rename keys inside frozen validation JSON files.

All new manuscript prose, figure labels, captions, cover letters and README text use the ecology-facing terms above.

"Connectivity" is used cautiously because the endpoint is an occurrence-pattern criterion, not an estimated movement process or dispersal rate.
